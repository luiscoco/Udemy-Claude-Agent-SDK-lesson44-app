Install the SDK, configure your key and run the classroom comparisons.

01

Prerequisites

Use Node.js 24+, API credit and Sonnet/Opus model access. Install Git Bash on Windows if the SDK requires it. No GitHub token or managed-agent IDs are needed.

node --version
npm --version
02

Install and configure .env

Install locked dependencies. Preserve an existing .env file and enter your own API key privately. Shell variables take precedence over the file.

cd .\agent-sdk\lesson44-invoking-subagents
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the server terminal open. Use all five student pages. If the port is occupied, the app prints an actionable message; update PORT and restart as needed.

npm start
# http://127.0.0.1:3144
04

Compare invocation and factories

Automatic does not name a specialist in its task. Explicit does. Balanced and Strict build different prompt/model definitions at runtime, with identical read-only tools.

npm run sample:env -- automatic
npm run sample:env -- explicit
npm run sample:env -- balanced
npm run sample:env -- strict
05

Trace and resume a child

Detect shows native Agent tool IDs and correlated child messages. Resume performs two parent queries with the same definitions and session, then sends the existing child a follow-up. Inspect stable agent_id and the absence of file reads during follow-up.

npm run sample:env -- detect
npm run sample:env -- resume
06

Compare tool sets and precedence

Readonly permits analysis only. Tests executes a fixed real assertion suite with its intentional failure. Precedence verifies a programmatic reviewer overrides a same-name filesystem agent. All temporary fixtures and transcripts are removed after collection.

npm run sample:env -- readonly
npm run sample:env -- tests
npm run sample:env -- precedence
npm test

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. All experiments finish automatically. Inspect an Agent tool-use ID without sending another model prompt. Consume the entire query stream: asynchronous child completions can produce multiple native parent result frames. Change PORT if 3144 is occupied.
