Choose automatic or explicit invocation

Compare an unnamed specialist request with a prompt that names security-reviewer. Description matching is model behavior; inspect actual Agent calls to confirm selection.

02

Build definitions at runtime

A typed factory changes the reviewer prompt and model: balanced uses Sonnet, strict uses Opus. Both keep the same read-only tools; stronger models do not guarantee better results.

03

Trace parent and child identities

Distinguish the parent session_id, Agent tool-use ID, parent_tool_use_id and child agent_id. Display actual nested calls and lifecycle reports.

04

Resume actual child history

Run discovery, capture the parent session and child ID, then query again with the same definitions and resume option. SendMessage targets that existing child; prove its ID stays stable.

05

Use the smallest tool set

A reviewer can read and search. The test runner can run one exact Node test command. Independent fixture hashes confirm no edits.

06

Troubleshoot missing delegation and collisions

Sharpen descriptions or name a specialist explicitly. Inspect a real same-name filesystem definition overridden by the programmatic agents option. New agents directories require a fresh session.
